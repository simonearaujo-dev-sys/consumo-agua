 ## 📌 Sobre o Projeto 💧
 > Programa desenvolvido em *Python* que classifica o consumo mensal de água, com o objetivo de *conscientizar o uso* e orientar sobre *economia de recursos naturais*. O usuário informa o nome do morador e o consumo em m³, e o sistema retorna a categoria e uma mensagem personalizada de acordo com as faixas estabelecidas.
 ---
 ## 📊 Regras de Classificação Implementadas 📈
 | 💧 Consumo (m³) | 🎯 Categoria | 💬 Mensagem Exibida |
 |---|---|---|
 | *Até 5 m³* | 🟢 Baixo Consumo | Parabéns! Você está consumindo de forma consciente. |
 | *De 6 a 10 m³* | 🟡 Consumo Moderado | Atenção! Tente reduzir o consumo para economizar recursos. |
 | *De 11 a 20 m³* | 🟠 Alto Consumo | Alerta! O consumo está elevado. Revise o uso da água. |
 | *Acima de 20 m³* | 🔴 Consumo Excessivo | URGENTE! Consumo muito alto. Economize água imediatamente! |
 > ✅ *Exemplo de execução testada:*
 > - Morador: *Simone Araújo*
 > - Consumo informado: *8 m³*
 > - Resultado: 🟡 *Consumo Moderado* ✅

 ## 🧠 Estrutura Lógica do Código
 O programa foi desenvolvido utilizando *estruturas condicionais* (if, elif, else) para verificar em qual faixa de consumo o valor informado se encaixa:
 - *if consumo <= 5* → Classifica como Baixo Consumo
 - *elif consumo <= 10* → Classifica como Consumo Moderado
 - *elif consumo <= 20* → Classifica como Alto Consumo
 - *else* → Classifica como Consumo Excessivo
 > 📝 O código contém *comentários explicativos* em cada bloco, facilitando a compreensão de cada etapa de execução.
